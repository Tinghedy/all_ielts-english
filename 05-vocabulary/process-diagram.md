## 易混淆

| 對比 | 差別 |
|---|---|
| include / involve / consist of | 其中一部分 / 必經內容 / 全部組成 |
| above / on / over | 在上方（不一定接觸）/ 有接觸 / 越過（移動） |
| along / through | 沿著長條物 / 穿過內部 |
| rise / raise | 自己上升 / 舉起某物 |
| log / firewood / wood / woods | 一段木柴（可數）/ 柴火總稱 / 木材 / 樹林 |
| smoke（名詞）不要換成 | fumes（有毒氣體）、vapour / steam（水蒸氣） |

## 萬用句型（流程圖）

| 句型 | 例句 |
|---|---|
| The process involves / consists of N stages | The process involves three stages. |
| beginning with … and ending with … | beginning with air entering the system and ending with meat and fish being smoked |
| It starts when … and ends when … | It starts when air enters the system and ends when meat and fish are smoked. |
| with only X + 分詞 / 介系詞片語 | with only a wooden box situated above ground level |
| After + V-ing, … | After passing over some bricks, the smoke rises… |
| …, which + 動詞 | The logs produce smoke, which travels through a pipe. |
| …, where + 子句 | …into the wooden box, where the meat and fish are cured. |
| the + 動作名詞 + of | the intake of air / the production of smoke |
