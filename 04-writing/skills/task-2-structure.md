# Task 2 四段式結構（250 字 / 40 分）

**狀態**：🔴 未開始
**所屬**：[[04-writing/README|Writing 寫作]]

## 這是什麼
開頭 → 讓步 → 主論點 → 結論。各題型的段落配置見 [[skills/task-2-question-types|Task 2 五種題型]]，範文見 [[essays/models/task-2]]。

## 必要技巧
- 開頭：改寫題目 + 明確立場
- 讓步段：承認對方合理處
- 主論點段：理由 + 具體例子
- 結論：重申立場，不加新論點

> `[]` 內是要填的內容

### 開頭段
背景句（引入話題）：
- In recent years, there has been a growing debate about [topic].
- The question of whether [issue] has become a contentious issue in today's society.
- With the rapid development of [field], [topic] has attracted considerable attention.

立場句（Thesis Statement）：
| 題型 | 句型 |
|---|---|
| 同意與否 | I strongly believe that… / While there are valid arguments on both sides, I am inclined to believe that… |
| 討論雙方 | While [view A] has some merit, I believe that… |
| 優缺點 | This essay will analyse the advantages and disadvantages of [topic] and argue that the benefits outweigh the drawbacks. |
| 問題解決 | This essay will explore the major causes of this problem and suggest some possible solutions. |

### 主體段：PEEL
| 步驟 | 功能 | 句型 |
|---|---|---|
| Point | 主題句，只講一個觀點 | One of the main advantages of [topic] is… / The primary reason why… is that… / Critics of [topic] argue that… |
| Explanation | 解釋為什麼 | This is significant because… / This phenomenon can be attributed to… |
| Example | 具體例子 | For instance, … / A case in point is [example], which demonstrates… / This is exemplified by the situation in [place], where… |
| Link | 收回論點 | This clearly demonstrates that… / This example illustrates the importance of… |

### 結論段
- 重申立場：In conclusion, I firmly believe that… / To conclude, the evidence suggests that…
- 總結論點：As discussed, the main reasons for this are…
- （可選）建議：To address these challenges, governments and individuals should consider… / A balanced approach would involve… while also…

## 常見錯誤
- 立場句只說 This essay will examine both sides，沒說自己站哪邊
- In my opinion, I strongly believe…（意思重複，二選一）
- 主題句太籠統（This problem has many causes），沒有具體論點
- 結論加入新論點
