# Task 1 圖表描述（150 字 / 20 分）

**狀態**：🟡 練習中
**所屬**：[[04-writing/README|Writing 寫作]]

## 這是什麼
線圖、長條、圓餅、表格、流程、地圖。各題型句型見 [[skills/task-1-chart-types|Task 1 六種圖表句型]]，範文見 [[essays/models/task-1-academic]]。

## 必要技巧
- Overview 段必寫：兩個最大趨勢
- 數據分組，不逐一列出
- 比較與趨勢用語：rose sharply, remained stable

### 四段骨架
| 段落 | 功能 | 不要做 |
|---|---|---|
| Intro（1–2 句） | 改寫題目 | 分析數據、列零件 |
| Overview（1–2 句） | 2–3 個主要特徵：最高 / 最低、主要趨勢、明顯對比、起訖變化 | 寫具體數字 |
| Body 1 + 2 | 分組描述，挑代表性數據（最高 / 最低、轉折點） | 把數字全列一次 |

### Intro 改寫
> `[]` 內是要填的內容

- The [chart type] illustrates / presents / gives information about [topic] in [place] between [year] and [year].
- The [chart type] provides a comparison of [items] in [place] from [year] to [year].
- Changes in [topic] over the period from [year] to [year] are illustrated in the [chart type].

三個地方都要換：動詞（shows → illustrates）、句型、時間（from 1990 to 2000 → over a decade between 1990 and 2000）。

### Overview 句型
- Overall, it is clear that [main feature 1], while [main feature 2].
- In general, the most noticeable trend is that [feature], while [feature].
- Overall, there was a significant [increase / decrease] in [item], with the [highest / lowest] figure occurring in [time / place].

### Body 分組
| 分組依據 | 例子 |
|---|---|
| 時間 | 前期 / 後期 |
| 類別 | 城市 / 鄉村 |
| 趨勢相似 | 上升的一組 / 下降的一組 |
| 數值高低 | 高值組 / 低值組 |

- 每段開頭先點出該段重點：Looking at the three main cities, New York showed the most dramatic population growth…
- 換組過渡：Turning to… / Regarding… / As for…

### 流程圖
- 四段：Intro（改寫題目一句）→ Overview（結構特徵 + 步驟數 + 起訖點）→ Body 1 → Body 2
- 結構 + 流程混合題：Overview 兩句各負責一半
- 只寫觀察，不寫推論
- 字數目標 160–180

## 常見錯誤
- 冠詞：第一次提到用 a，第二次用 the
- Overview 寫成 Body（逐步描述 + 零件）
- 寫圖上沒有的目的 / 功能（推論）
- 沒寫 Overview，或 Overview 放了具體數字
