# Task 2 五種題型

**狀態**：🔴 未開始
**所屬**：[[04-writing/README|Writing 寫作]]

## 這是什麼
依題目問法決定段落配置。開頭、主體、結論的通用句型見 [[skills/task-2-structure|Task 2 四段式結構]]，範文見 [[essays/models/task-2]]。

| 題型 | 題目問法 | 第一件事 |
|---|---|---|
| 同意與否 | To what extent do you agree or disagree? | 決定完全同意 / 反對，或部分同意 |
| 討論雙方 | Discuss both views and give your own opinion. | 兩邊都寫，還要有自己的立場 |
| 優缺點 | What are the advantages and disadvantages? / Do the advantages outweigh…? | outweigh 題要明確判斷 |
| 問題解決 | What are the causes… and what measures…? | 看題目只問成因、只問解法，還是都問 |
| 雙問題 | 兩個獨立問句 | 兩題都答，不能漏 |

## 必要技巧

> 預設寫四段（開頭 + 兩段主體 + 結論），每段主體 80–100 字，全文 270–300 字，40 分鐘寫得完。

### 同意與否
| 段落 | 完全同意 / 反對 | 部分同意（讓步） |
|---|---|---|
| 開頭 | 明確表態 | 表達平衡立場 |
| 主體 1 | 理由 1 + 解釋 + 例子 | 不同意的方面 + 解釋 + 例子 |
| 主體 2 | 理由 2 + 解釋 + 例子 | 同意的方面 + 解釋 + 例子 |
| 結論 | 重申立場 + 總結 | 重申平衡立場 + 總結兩面 |

- 完全同意：I completely agree with the view that…
- 完全反對：I strongly disagree with the statement that…
- 部分同意：While I agree with this view to some extent, I believe there are important limitations.
- 部分反對：Although there is some merit in this argument, I largely disagree with the statement.

### 討論雙方
| 段落 | 內容 |
|---|---|
| 開頭 | 引入爭議 + 雙方觀點 + 自己的立場 |
| 主體 1 | 觀點 A + 解釋 + 例子 |
| 主體 2 | 觀點 B + 解釋 + 例子，並說明為何較認同這邊 |
| 結論 | 重申立場 + 總結雙方 |

- 呈現雙方：Some people maintain that…, while others contend that… / Proponents of the first view argue that… On the other hand, those who support the second perspective believe that…
- 給立場：After considering both perspectives, I am inclined to support the view that… / While both arguments have merit, I find the second view more convincing because…

### 優缺點
| 段落 | 內容 |
|---|---|
| 開頭 | 引入話題；outweigh 題要先表態 |
| 主體 1 | 主要優點 + 解釋 + 例子 |
| 主體 2 | 主要缺點 + 解釋 + 例子 |
| 結論 | 總結 + 判斷 |

- 優點：The main advantage of [topic] is… / One positive aspect that cannot be overlooked is…
- 缺點：However, there are also significant drawbacks, such as… / A key concern regarding [topic] is…
- 權衡（outweigh 題）：When weighing these factors, it becomes clear that the advantages outweigh the disadvantages because… / Although there are legitimate concerns, the benefits are more significant in terms of…

例：The advantages of international tourism outweigh the disadvantages. 優點：經濟效益、文化交流、基礎建設；缺點：環境、文化商品化、經濟依賴；權衡：長期多元化與保護措施可減輕負面影響。

### 問題解決
| 段落 | 內容 |
|---|---|
| 開頭 | 問題背景 + 嚴重性 |
| 主體 1 | 成因 1、2 + 解釋 + 例子 |
| 主體 2 | 對應成因的解法 + 可行性 + 例子 |
| 結論 | 總結 + 強調行動 |

- 成因：One of the primary causes of [problem] is… / This problem stems largely from… / A major factor contributing to this issue is…
- 解法：An effective approach to addressing this problem would be… / To tackle this issue, [who] should consider… / A viable solution might involve…
- 銜接：Having identified [cause] as a major contributor to the problem, a targeted solution would be…

例：城市肥胖問題。成因：久坐與速食文化、城市規劃不利運動；解法：教育與獎勵機制、改善都市規劃與健康食物取得。

### 雙問題
| 段落 | 內容 |
|---|---|
| 開頭 | 引入話題 + 點出兩個問題 |
| 主體 1 | 回答第一題 |
| 主體 2 | 回答第二題 |
| 結論 | 總結兩題 |

- 點題：This essay will address two key questions: firstly, [Q1]; and secondly, [Q2].
- 切換：Turning to the first question regarding… / With regard to the second question about… / Having addressed [Q1], it is now important to consider [Q2].

例：What factors influence children's attitudes to learning? How can these attitudes be improved? 因素：家庭、學校；改善：父母參與與榜樣、互動教學與個人化學習。

## 常見錯誤
- 題型判斷錯：討論雙方卻只寫一邊，問成因和解法卻只答一半
- 題目限定對象或角度（政府、青少年）卻寫得很籠統
- 主體段落太多，時間不夠，每段都寫不深
